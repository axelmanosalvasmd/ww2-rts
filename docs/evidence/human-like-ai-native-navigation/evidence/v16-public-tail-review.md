The private restriction is required. A generic public object can change its flags array without advancing its region version, yielding a newly connected coarse graph while the original cached region check rejects the route. An incomplete height array can also produce disagreement. The patch tracks only internally created complete typed observed views in a private WeakSet, propagates membership to their internally created vehicle clearance views, and leaves the original check in place for every generic input. The private observed constructor updates knowledge, movement and obstruction versions together. World views already bypass the region check. No public keys, terrain data, command timing, RNG, planner cadence, difficulty, limits, warmup or whole-AI measurement boundary change.

The connectivity proof follows the actual source. Coarse component links use legal cardinal moves. Directed crossings require legal heights, open diagonal corners and legal source corner heights. Every such edge is accepted by the full-map region graph, and every emitted local goal lies on that connected route. Null-height diagonals have a legal cardinal substitute. An independent agent examined 43,220 isolated tiny graph/leg comparisons, including 5,776 eligible connected legs, with no disagreement, and reviewed the private provenance patch. This is a source proof supplemented by bounded controls, not a native acceptance claim.
