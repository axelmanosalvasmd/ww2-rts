# Once-per-visit hesitation proposal

The immutable V16 Easy seed1 timeline contains a real repeated hesitation defect. In the same attended contact episode, the native default planner proposes Rifle 14's useful local attack-move at tick 1595 and again at tick 1625. Baseline throws away both choices and waits two 30-tick intervals. The rifle is alive, stationary and already physically selected. Hands are free; no input cap or unfinished motor action accounts for these empty intervals.

The source patch samples hesitation once for an attended visit, identified by its existing public concern ID, event ID, event time and visit start. It retains the authored Easy/Normal/Hard probabilities (.25/.12/.04) and 30/16/8-tick pauses. Replanning keeps the same deadline. A held useful advance is excluded from the existing empty-combat deferral, so a retry cannot falsely expire that visit. Another genuinely new or reacquired visit receives its own decision. Other commands can still proceed, and accepted movement, attention, fog, selection, reaction, motor costs, input caps and resource guards remain unchanged.

The unchanged V16 source is under `baseline/`; `candidate/` differs only in `shared/ai-commander.js`. Baseline commander SHA256 is 214cfdf199c02afbba40a2958a8df05a95c3588f4bd0d1cc08c5bcbe6dc9ae01. Candidate commander SHA256 is 19112a1e4c94da72d62564d940497d38cf7e93e3086c9bde3db9c29d088703df. `manifest.json` records all six involved runtime modules and exact artifact bytes/hashes. The patch applies cleanly to current repository source; no repository file was changed.

Suggested changelog bullet: "Computer commanders can hesitate before a risky advance, then carry out the same useful plan after the pause instead of repeatedly postponing it."

Suggested design note: "Risky combat advances sample hesitation once per attended public visit at the existing difficulty rates. A hesitation retains the full existing pause deadline across replanning and does not count as an empty combat visit. New public episodes or genuinely reacquired visits remain eligible. All motor costs, reaction timing, input caps and information boundaries remain unchanged."
