# R8-3: repeated empty guard visits

The narrow defect is that idle attention forgets a genuinely empty, watched visit to an infantry guard. It repeatedly pays to return to that unchanged actor. Combat-area backoff cannot help because these concerns are named idle visits. Ordinary periodic inspection remains appropriate; five identical MG trips in one quiet minute do not add useful information.

The candidate records only an owned, on-screen, actually idle infantry guard after planning leaves no command intent or inspection request. A guard must occupy a friendly objective, trench, garrison, or explicitly held position. Engineers, medics and ordinary unguarded idle actors remain eligible. The record defers only that named idle concern, for at most 600 ticks (30 seconds). All existing combat, alert, objective, repair, production and scouting concerns remain independent.
