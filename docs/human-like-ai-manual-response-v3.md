# Prospective manual-response v3

Adopted on 2026-10-04 after source review and native controls, this corrects two measurement gaps from review R7. Final campaign acceptance remains open. The explicit policy is `screen-manual-v3`; its detached stream is `ww2-public-manual-response-v3`. The existing v2 helper and capture files remain byte-identical. The collector selects the version explicitly and reduces historical v2 streams with v2. No V16 raw event, metric or result is rescored. The original oracle and observed streams remain unchanged.

Creation rules remain unchanged: contact candidates are idle controllable ground combat actors within 45m; damage uses the existing displayed 25% loss or retreat-risk crossing. Automatic combat, provable automatic retreat and fortified holds retain their original conditions. A passive out-of-range contact without separately proved in-flight coverage remains required.

The purpose table adds damaging support only over a visible enemy legally threatening an affected actor. Dive uses its 5m point blast. Artillery uses its 24m by 10m scatter strip, with 4m blast expansion for visible-friend exclusion. Bombing uses its 40m line and actual 3m lateral scatter, expanded by 7m blast for friend exclusion. Strafe uses its 36m by 8m native strip. Direction uses the actual command angle or the public own spawn fallback. Every visible friend in the conservative hazard region rejects credit. Infantry requires positive infantry damage or suppression; armor requires vehicle damage greater than infantry damage. Thus weak strafing of armor remains unsupported. Accepted-command credit still requires actual authoritative acceptance and public click-time purpose.

Suppress requires an actual ready selected-HUD actor, stationary/setup legality, current visible infantry target, useful suppression and a legal firing line serving the affected actor. AP requires the same readiness and a useful current non-infantry, non-structure target, including any native naval restriction. Already active suppression or loaded AP cannot create credit. This proposal conservatively admits only direct AP weapons without salvo, area, blast or terrain-impact effects. Other AP variants remain deferred because their public friend-hazard proof was not completed within this scope. Native direct projectiles exclude allied actors; the proposal does not infer future damage.

A new contact can be monitoring when an actual issuing attack/attack-move pointer motor was already physically active at creation. Its registered-at-start native receipt must prove the actual operation, pointer chord, selected actor, earlier immutable public cue and active interval. The earlier cue must independently recompute as required for that actor. The unchanged public purpose predicate must also cover the new contact. Selection actions, queued-only plans, future starts, completed motors, unrelated geometry, absent selected actors and missing earlier public causes cannot qualify. Queued movement commands and minimap issuing gestures are excluded from this narrow proposal. No future acceptance, later death or disappearance establishes creation eligibility. The later contact gets no zero-time answer or latency sample.

All numeric limits remain unchanged: screen Easy 0.9–1.4s, Normal 0.5–0.8s and Hard 0.3–0.45s; off-screen 3–6/1.5–3/0.8–1.6s; physical APM 20–35/40–70/80–120; peak 60/120/200; first order 4–8/3–6/2–4s; reaction floor 0.2s. Every required unanswered row remains end-censored, every unknown remains unknown and original full populations are retained.

Focused native proof passes all four damaging support forms, direct AP and suppress with real physical inputs and accepted native commands. Friend hazards, wrong footprints, unsupported recon/abilities, missing readiness, wrong actors and a genuinely refused unfunded support command remain uncredited for acceptance. A second enemy moves into the actual screen during a pointer motor starting at110 and ending at118; the contact at112 is monitoring with no answer. Queued, completed, wrong-selection, absent-cause, wrong-geometry and clock controls remain required. Mutating detached observer proofs preserves the complete native game graph, RNG, commands and physical inputs. The existing 162 creation/policy assertions also passed against the v3 prototype; v2 remains unchanged.

The permanent `test-engine-ai-manual-response-v3.js` passes on the adopted checkout and is registered in `node test.js`. Its source hashes, original proposal, native proof and root test output are retained in `docs/evidence/human-like-ai-manual-response-v3/`. No campaign has been run with this policy. Gameplay, APM, off-screen population and other open gates remain open.
